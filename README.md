# cleargridstudios.com

Static marketing site for [ClearGridStudios](https://cleargridstudios.gumroad.com) — spreadsheets & templates with formulas that provably work.

- Generated by `build.py` (no dependencies): edit content there, run `python3 build.py`, commit.
- Served by GitHub Pages from `main` / root; custom domain via `CNAME`.
- Source of truth mirrored in the private ops repo (`business-2/site/`).
